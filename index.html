REFERENCE

Documentation

01

How it works

NOVA BUILDER mengirim isi file ke endpoint /api/deploy. Endpoint tersebut berjalan sebagai Vercel Function dan menggunakan secret environment variable VERCEL_TOKEN.

02

Why server-side token

Jangan menaruh Vercel token langsung di HTML/JavaScript WebView. Token di browser dapat terlihat oleh pengguna lain dan berisiko disalahgunakan.

03

Project name

Nama proyek Vercel harus lowercase dan hanya memakai huruf, angka, titik, underscore, atau tanda minus.

04

Sketchware WebView

Load URL NOVA BUILDER pada WebView. Pastikan WebView mengizinkan JavaScript dan file chooser jika ingin memakai pemilih file.

05

First setup

  1. Deploy folder NOVA BUILDER ke akun Vercel.
  2. Di Project Settings → Environment Variables, buat VERCEL_TOKEN.
  3. Masukkan Access Token Vercel sebagai nilainya.
  4. Redeploy NOVA BUILDER setelah variable tersedia.
  5. Buka NOVA BUILDER dari WebView Sketchware.
06

Supported workflow

Versi ini fokus pada static HTML/CSS/JS. Untuk framework seperti Next.js, gunakan Git/CLI/Vercel Drop atau workflow build khusus karena proyek framework memerlukan proses build.
